[[Clustering]] is an [unsupervised machine learning](https://www.ibm.com/think/topics/clustering) technique that automatically groups similar data points together based on shared characteristics without knowing and using predefined classes.

## How it works

- **Unsupervised:** It works on unlabeled data, meaning the computer finds patterns on its own.

- **Similarity:** It measures distance or closeness (like [[Euclidean distance]]) to put similar items in one group and different items in separate groups.

- **Goal:** Items in the same cluster are very alike, while items in different clusters are distinct. [[1](https://developers.google.com/machine-learning/clustering/overview), [2](https://www.sciencedirect.com/topics/earth-and-planetary-sciences/clustering), [3](https://www.geeksforgeeks.org/machine-learning/clustering-in-machine-learning/)]

## Common Uses

- **Market Segmentation:** Grouping customers by buying habits for tailored ads.

- **Anomalies:** Finding outliers or fraud in financial data.

- **Organization:** Sorting documents or images by topic.
