# Technology
Dendrites - Reciever
Axon - Transmiter
Synapse - Connection - Weight

Basic building block of a [[Neural Network]].

Input layer/value are the standardized independent values (0-1).
Output layer/value can be:
- Continuous (price)
- Binary
- Categorical (several output variables)
Both are the same observation and a single observation.

In the neuron:
- 1. add up the values / weighted sum
- 2. applies an [[Activation Function]]
- 3. pass the signal to the next neuron
