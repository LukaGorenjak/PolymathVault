==Is a mathematical formula applied to a neuron's input in a neural network to decide whether and how strongly to pass the signal on.==

---
## **Threshold Function:**
- 1 if x >= 0
- 0 if x < 0

## **Sigmoid Function:**
- 1 / (1+e^-x)
- Gradual progression
- Useful in the Output layer when predicting probability.

## **Rectifier Function:**
- max(x, 0)
- On of the most used

## **Hyperbolic Tangent Function (tanh):**
- (1-e^-2x) / (1+e^-2x)
- Similar to Sigmoid but goes from -1 to 1
