- Is when you apply ML models to text or language, teaching a machine what is said or spoken.
- NLP can be used for text review, on an article to predict some categories, predict genre of a book. You can go further and build machine translators or speech recognition system.
- Most NLP models are classification models, some: 
	- Logistic Regression, [[Naive Bayes]], CART, Maximum Entropy, Markov Models
- A well known NLP model is the [[Bag-of-Words]], it is used to preprocess text before fitting a classification algorithm on the observation containing text.

**Types of NLP:**
- Natural Language Processing - NLP
- Deep Natural Language Processing - DNLP (overlap of NLP and DL)
	- [[Seq2Seq]] (cutting edge models)
- Deep Learning 
 
**Classical vs DL Models**
Some examples: 
- If / Else rules (Chatbot)
- Audio frequency components analysis (Speech Recognition)
- [[Bag-of-Words]] model (Classification) 
- [[CNN - Convolutional Neural Network]] for text Recognition (Classification)
- [[Seq2Seq]] (many applications)
